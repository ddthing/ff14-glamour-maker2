# 한국어 문구 윤문 결과

## 작업 범위

프로젝트에서 실제 이용자에게 보이는 한국어 문구를 대상으로 문체와 호흡을 다듬었습니다. 편집기 UI, 상태·오류 메시지, 이용약관·개인정보처리방침·가이드·문의·후원 페이지, 정적 fallback과 API 오류 응답을 포함합니다.

영어·일본어 문구, 개발 문서, 테스트 시나리오 문장, 아이템명과 기능명은 의미와 계약을 보존하기 위해 윤문 대상에서 제외했습니다. 기능·레이아웃·데이터 형식은 변경하지 않았습니다.

## 적용한 기준

- 번역투와 설명서식 표현을 줄이고, 화면 맥락에 맞는 짧은 문장으로 정리했습니다.
- `클릭해서`, `선택해 주세요`처럼 반복되던 표현은 문맥에 따라 `클릭해`, `골라 주세요`, `보여드립니다` 등으로 분산했습니다.
- `이름을(를)`처럼 기계적인 조사 표기를 없애고 자연스러운 문장 구조로 바꿨습니다.
- 법률·개인정보 안내는 과하게 구어체로 바꾸지 않고 의미와 책임 범위를 유지했습니다.
- API 오류 응답은 띄어쓰기와 안내 말투만 통일했습니다.

## 대표 변경

- `여러 캐릭터를 한 장에 배치하고...` → `여러 캐릭터를 한 장에 담고...`
- `클릭해서 카드 제목 편집` → `클릭해 카드 제목 편집`
- `원하는 후원 서비스를 선택해 주세요` → `원하는 후원 서비스를 골라 주세요`
- `{name}을(를) ... 연결했습니다` → `{meta}에 {name} 아이템을 연결했습니다`
- `이미지 해상도가 ... 이하로 선택해 주세요` → `... 이하 이미지를 사용해 주세요`

## 상태

- 사용자 노출 문구 윤문: 완료
- 의미·기능 변경: 없음
- 변경률: 문구 토큰 중심의 제한적 변경. 코드 구조와 시각 레이아웃은 변경하지 않음.

## 검증

- `npm test` — 89/89 통과
- `npm run check` — 통과
- `npm run build` — 공개 사이트 산출물 생성 및 검증 통과
- `git diff --check` — 오류 없음. 기존 파일의 LF/CRLF 변환 경고만 출력됨.
