사용 가이드

사진과 장비, 문구를 정리한 뒤 미리보기 그대로 PNG로 저장하면 됩니다.

최종 수정일: 2026년 9월 8일

1. 인원수와 사진 정하기

  1. 1~5인 구성을 고르세요.
  2. PNG, JPG, WebP 사진을 한 장 또는 여러 장 불러오세요.
  3. 카드 미리보기에서 프레임과 위치, 크기를 조정하세요.

2. 장비 정보 추가하기

  1. 장비 탭에서 이름이나 ID를 검색하세요.
  2. 아이템을 추가한 뒤 바꾸거나 지울 수 있습니다.

3. 카드 꾸미기

제목과 설명, 정렬, 색상, 서체, 테두리와 배경을 카드에 맞춰 조정하세요.

4. 미리보기와 저장 확인

현재 미리보기의 배치와 스타일을 확인한 뒤 PNG 내보내기를 누르세요.
