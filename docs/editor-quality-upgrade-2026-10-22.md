# 편집기 품질 업그레이드

기준: 2026-10-22, `85b61ef` 이후 변경. 디자인 기준은 기존 `DESIGN.md`다.

## 제품 방향

캐릭터와 완성된 카드가 가장 먼저 보이는 Neutral 편집기를 유지한다. 장식 추가보다 입력부터 PNG 저장까지 결과가 예측 가능한 편집 경험을 우선한다. 화면의 밝기 설정은 작업 환경에만 적용하고 카드의 배경색·글자색·내보내기 설정과 분리한다.

## 구현 범위

- 편집기 표면·여백·인스펙터 정보 위계를 정리하고, 기존 Neutral 다크 토큰으로 밝은/어두운 화면 전환을 제공한다.
- 스크랩북·콜라주 장비 노트의 종이 색상, 질감 위치와 테이프를 공유 재질 정의로 맞춘다. 미리보기에서 선택한 스타일이 PNG에도 반영되어야 한다.
- 한국어·일본어 룩 제목을 PNG 파일명에 보존하고, 파일 시스템에서 위험한 문자와 과도한 길이는 정규화한다.
- 번역 적용 시 DOM 검색을 통합하고 글자 줄바꿈 측정에서 Range 객체를 재사용한다. 드래그 렌더링은 화면 갱신 주기에 맞춰 합치되 마지막 위치와 실행 취소 기록은 보존한다.
- GPU 서비스에서 모호한 HTTP 본문 길이를 거부하고 업로드 시간·요청 스레드 수를 제한한다. 빌드 출력은 정해진 생성 폴더로 제한하고 심볼릭 링크·정션을 통한 경로 이탈을 차단한다.

## 검증 원칙

기존 Edge 회귀 검사에 화면 테마, 다국어 파일명, 객체 생성 횟수, 드래그 갱신 횟수와 빌드 경로 검사를 추가한다. GPU 서비스의 HTTP 검사는 실제 루프백 소켓과 Pillow를 사용하지만 추론 엔진은 대역으로 교체하므로 GPU 품질·처리량 검증을 뜻하지 않는다.

DOM 검색 횟수와 객체 할당 수 감소는 코드 경로에 한정된 개선이다. 실제 사용자 기기에서의 로딩 시간, 메모리 절감률 또는 전체 서비스의 처리량 개선율로 확대 해석하지 않는다.

최종 로컬 검증에서 `npm run check`, Edge 회귀 검사 99/99, `npm run build:pages`, Python HTTP 경계 검사와 `git diff --check`가 통과했다. 테마 검사에서는 8px의 외곽 모서리를 제외한 카드 미리보기의 변경 픽셀이 0개였고 PNG는 바이트 단위로 동일했다. 검사한 어두운 화면의 8개 대표 글자·컨트롤 대비는 최소 10.06:1이었다. 빌드에는 실제 한국어 아이템 24,203개가 부위별로 분할됐다.

## 출시 품질 확인에 남은 것

- 실제 FFXIV 원본을 사용한 1·2·5인 카드의 얼굴·손·의상 실루엣과 긴 장비명 검토. 자동 검사에 쓰는 합성 이미지는 기하·내보내기 회귀 검증용이다.
- 실제 iOS/Android 기기, VoiceOver/NVDA, 저사양 기기에서의 편집·복원·PNG 저장 확인.
- 외부 모델 다운로드와 실제 WebGPU/WASM 배경 제거 품질·지연 시간 측정.
- GPU 서비스가 설정된 배포 환경의 인증·업로드 제한·부하 테스트.

이 변경의 자동 검사 통과만으로 수상 수준의 시각 품질이나 상용 서비스 전체의 보안을 인증하지 않는다.
