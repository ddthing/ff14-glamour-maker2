# 카드 아트 디렉션

첨부된 룩북 레퍼런스에서 반복되는 시각 문법을 카드 레시피에 연결한다. 목표는 장식을 많이 넣는 것이 아니라, 제목·인물·장비 정보의 위계를 먼저 정한 뒤 인쇄물처럼 보이는 한 가지 장치를 선택하는 것이다.

## 공통 구성

1. 배경은 단색 또는 낮은 대비의 질감으로 둔다.
2. 제목은 카드 안의 마스트헤드에서 편집한다. 제목 영역을 먼저 확보해 인물 머리가 잘리지 않게 한다.
3. 인물은 정보보다 앞에 있는 주인공이다. 1인은 전신 인물을 크게 두고 장비 노트를 좌우로 교차 배치한다.
4. 3–5인은 제목을 가운데 두고 인물을 균등한 열로 배치한다. 정보는 기본적으로 선택적으로 켜며, 표시할 때 인물은 흐리게/실루엣으로 한 단계 낮춘다.
5. 별·하트는 텍스트 기호가 아니라 CSS 도형으로 만든다. 문자 모양이 OS 폰트에 따라 달라지는 문제를 피한다.

## 레시피와 레퍼런스 연결

| 레시피 | 참고한 문법 | 카드에서 고정하는 장치 |
| --- | --- | --- |
| 조용한 종이 | 여백이 많은 화이트 룩북 | 무늬 없음, 얇은 규칙선, G마켓산스 마스트헤드, 아이보리 정보 노트 |
| 블루 비트맵 | 청색 망점·비트맵 인쇄지 | 모서리 하프톤 클러스터, 청록 잉크, 제목 왼쪽 규칙선, ZEN SERIF |
| 소프트 픽셀 | 파스텔 도트·빛나는 별 배경 | 중앙 대비를 낮춘 도트 그라데이션, 작은 CSS 스파클, 학교안심 둥근미소 |
| 스크랩북 팝 | 종이 라벨·테이프·큰 타이포 콜라주 | 크림 종이 제목 라벨, 한쪽 테이프와 비대칭 회전, 스텔라체, 종이 정보 노트 |

## 금지 규칙

- 검은색 그라데이션 하나로 제목을 읽히게 만들지 않는다. 제목은 마스트헤드의 예약 공간과 대비·크기로 해결한다.
- 사진 위에 장비 이름을 투명하게 직접 얹지 않는다. 1인 장비 정보는 불투명 노트로, 3–5인 정보는 레퍼런스처럼 선택적 오버레이로 처리한다.
- 인원수와 무관하게 5개 열을 강제하지 않는다. 1인은 세로 4:5, 2인은 가로 16:9, 3–5인은 가로 라인업으로 자동 전환한다.
- 패턴·스티커·장식은 한 카드에서 두 가지 이상의 강한 문법을 동시에 사용하지 않는다.
