# Source-preserving card decoration

This implementation follows DESIGN.md; it does not replace its layout or gear-copy rules.

## Preservation contract

- Keep original uploaded blobs in IndexedDB. Decorations must never rewrite them.
- Treat background-removal output as an alpha mask only, for both server and browser results.
- Reject mismatched dimensions; never silently rescale the subject or mask.
- Retain decoded source RGB and cap output alpha at source alpha.
- A mask can still misclassify hair or equipment. Manual inspection and original restore remain necessary.
- Canvas PNG encoding may round RGB at translucent edges. Source blob identity, pre-encoding RGB preservation, and exported composition fidelity are separate checks.
- Existing user-selected fit, position and zoom remain available. Theme selection must never change them.

## Theme production brief

Use the public XXD Panel 207 repository as a composition reference for empty
background assets only; do not install or copy its raster-generation workflow.
Do not supply character screenshots. Generate no people, equipment, text, numbers,
logos, or item icons. Keep central subject and copy areas quiet. Prefer edge texture
and restrained print details. Review asset licensing before distributing assets.

Implement material layers with the existing pattern/texture axes. Avoid a second
template picker: DESIGN.md explicitly makes direct background controls the source
of truth. Presets may contain only background color, pattern and texture, never
typography, image placement or equipment data.

## Next implementation gates

Vintage scrapbook is now the first optional starter in the existing preset
panel. It applies paper / scrapbook / grain through the same background-only
action as saved presets. Its `assets/themes/vintage-scrapbook-plate.svg` asset
contains only hand-authored paper, tape, ink, and line shapes: no photos, text,
logos, item icons, or embedded raster data. Korean, English, and Japanese
labels are provided. Users can adjust the three axes and save their own
variant. This is a deterministic card material, not an output generated by the
external XXD skill.

Paper collage remains the second optional starter. It applies linen / collage / grain
and uses `assets/themes/collage-paper-plate.png` as a separate, text-free paper
mount. The plate is material support for the hero image, not a collection of
free-floating decoration. Equipment notes become opaque paper scraps with a
slot-colour tab, so the visual treatment also communicates which part of the
outfit each note describes. The preview and PNG renderer load the same plate,
use the same card geometry, and draw the same note treatment. No source image
pixels, item names, or user typography are sent through the generated asset.
