# 장비 등록과 카드 구성

투영세트메이커2는 기본 장비와 사용자가 추가한 장비를 캐릭터별로 관리합니다. 장비 정보는 카드에서 캐릭터 이미지와 함께 표시하거나, 전체 장비 시트로 따로 저장할 수 있습니다. 이 기능은 캐릭터 사진이 없어도 사용할 수 있습니다.

## 장비 부위와 등록 방식

기본 장비는 머리, 몸통, 손, 다리, 발의 다섯 부위입니다. 추가 장비는 무기, 액세서리, 얼굴 장식, 패션, 기타 그룹으로 나뉘며 액세서리에는 귀걸이, 목걸이, 팔찌, 왼쪽 반지, 오른쪽 반지가 포함됩니다.

현재 실제 아이템 카탈로그에서 검색할 수 있는 부위는 다음 10개입니다.

| 그룹 | 검색 가능한 부위 |
| --- | --- |
| 기본 장비 | 머리, 몸통, 손, 다리, 발 |
| 무기 | 무기 |
| 액세서리 | 귀걸이, 목걸이, 팔찌, 반지 |

왼쪽과 오른쪽 반지는 같은 반지 카탈로그를 사용하지만 카드에는 별도 부위로 저장합니다. 보조무기, 얼굴 장식, 패션 아이템과 기타 항목은 현재 검색 카탈로그에 포함되지 않으므로 직접 등록합니다.

직접 등록할 때는 현재 언어의 이름을 입력하고, 필요하면 영어 이름·일본어 이름·메모를 추가합니다. 카탈로그에서 연결한 장비는 원본 아이템 ID를 보관합니다. 추가 장비는 캐릭터마다 최대 32개까지 등록할 수 있으며, 사진을 넣지 않아도 등록·편집·삭제할 수 있습니다.

추가 장비마다 카드 표시 여부를 설정할 수 있습니다. 카드에 표시하는 추가 장비 개수에는 별도 제한이 없습니다. 표시 항목이 많아지면 장비 정보의 글자 크기를 줄여 카드 안에 맞춥니다. 카드에서 숨긴 항목도 등록 상태는 유지되며, 전체 장비 시트에는 등록된 장비를 모두 포함합니다.

여러 캐릭터가 있는 카드에서도 각 캐릭터가 선택한 항목을 모두 배치합니다. 항목이 아주 많거나 이름이 길면 카드 글자가 매우 작아집니다. 전체 장비 시트는 본문 글자 크기를 유지하고 페이지를 나누므로, 큰 글자로 전체 목록을 읽을 때 사용할 수 있습니다.

## 카드 정보와 이미지 구성

카드 구성은 장비 정보와 캐릭터 이미지의 앞뒤 순서를 정합니다.

- **정보 앞**은 장비 정보가 캐릭터 이미지보다 앞에 보이게 합니다.
- **인물 앞**은 캐릭터 이미지가 장비 정보 앞에 보이게 합니다. 이 배치는 이미지의 배경 제거를 완료한 경우에만 사용할 수 있습니다.
- **글자 보호**를 켜면 캐릭터 이미지가 장비 이름을 가리지 않도록 장비 정보 영역을 보호합니다.
- **정보 간격**은 장비 정보와 캐릭터 사이의 거리를 0–64px 범위에서 조절합니다. 값이 커질수록 장비 정보가 캐릭터에서 멀어집니다.

## 전체 장비 시트 저장

장비 시트는 등록된 기본 장비와 추가 장비를 부위별로 정리해 페이지로 나눕니다. 각 페이지는 2160 × 2700px입니다. 카드 표시 여부가 꺼진 장비도 시트에는 포함됩니다.

선택한 캐릭터의 장비 시트가 한 페이지면 PNG로 저장하고, 여러 페이지면 페이지별 PNG를 ZIP으로 묶어 저장합니다. 전체 활성 캐릭터를 내보낼 때는 캐릭터별 시트를 ZIP으로 저장합니다. 이 기능은 캐릭터 사진을 요구하지 않습니다.

## 한국어 아이템 데이터

현재 번들 한국어 아이템 snapshot에는 고정된 `Item.csv` 원본에서 만든 29,312개 레코드가 있습니다. 검색은 기본 장비 5개 부위, 무기, 귀걸이, 목걸이, 팔찌, 반지 등 10개 슬롯을 지원합니다. Pages 빌드에서는 전체 snapshot을 슬롯별 정적 인덱스로 나눠 현재 검색 부위에 맞는 데이터만 불러옵니다.
